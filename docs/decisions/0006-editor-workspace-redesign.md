# 0006：主页面采用编辑器式工作区

## 状态

已确认

## 背景

主页面需要同时承载元件选择、电路画布、仿真控制、节点属性和波形历史。原有页面更接近带有大标题的教学落地页，画布和控制区域的关系不够像用户熟悉的编辑器。

## 决策

主页面改为固定的编辑器工作区结构：

```text
顶部项目栏
├── 工具轨道
├── 可折叠元件 / 层级侧栏
└── 编辑区
    ├── 编辑工具栏
    ├── 电路画布
    └── 属性 / 波形面板
```

画布作为视觉主角，使用网格、正交连线和节点选中外轮廓表达编辑关系。颜色只表达语义状态：橙色表示高电平、紫色表示未知、绿色表示引擎或仿真就绪。编辑器的其余区域使用低对比度深色面板，并保留浅色主题的同一信息层级。

侧栏默认展示元件库，切换后展示当前电路层级；节点检查器固定在侧栏底部。波形默认收起，放在画布下方的面板中，避免初学者第一次进入页面时被历史数据打断。

## 结果

- 主页面不再使用大段营销式介绍，首屏空间优先给编辑和观察电路。
- 现有 Vue → Electron → C++ 仿真闭环保持不变。
- 通过缩放按钮、侧栏折叠和属性 / 波形切换，提供编辑器感但不引入额外复杂流程。
- 后续可在现有布局中接入真正的拖放添加、撤销重做和画布平移，而无需再次调整页面骨架。
