# ADR 0001：采用 Electron、Vue、TypeScript 和独立 C++ 引擎

## 状态

已接受

## 背景

项目需要同时使用 Vue、TypeScript 和 C++。桌面层、用户界面和仿真核心需要能够独立测试和演进。

## 决策

使用 Electron 承载 Vue + TypeScript 用户界面，使用独立 C++ 进程承载数字电路仿真引擎，通过 JSON 消息进行通信。

## 原因

- 避免桌面层一开始引入额外的 Rust 技术栈；
- C++ 引擎可以独立编译、测试和调试；
- 前端和仿真规则之间有清晰的 seam；
- 将来可以复用引擎开发 CLI 或其他界面；
- 进程通信错误和协议设计需要保持可观察、可验证。

## 代价

- 需要管理两个构建系统；
- 需要处理进程启动、退出和错误；
- JSON 通信性能不是最终最优方案；
- Electron 的资源占用高于更轻量的桌面方案。

## 后续复查条件

当性能、跨平台打包或部署复杂度成为实际问题时，再评估 C API、Node-API、Tauri 或其他集成方式。
