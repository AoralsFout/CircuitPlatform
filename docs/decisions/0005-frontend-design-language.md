# ADR 0005：采用引导式数字电路工作台设计语言

## 状态

已接受

## 背景

CircuitPlatform 的第一版前端需要同时满足两个目标：让初学者能够快速理解输入、逻辑门和输出之间的关系；保留数字电路工具应有的结构、状态和诊断能力。

如果直接采用通用后台或普通 SaaS 组件风格，电路节点、端口、连线和信号状态会失去产品特征。如果直接模仿复杂 EDA 软件，初学者又会面对过高的信息密度和学习成本。

当前桌面应用已经形成深蓝绿色背景、工程标签、网格画布、琥珀色活跃连线和薄荷色成功状态的初步方向，需要将其提升为跨页面和跨主题可复用的规范。

## 决策

采用“引导式数字电路工作台”作为前端设计语言：

- 中央电路画布是主工作区；
- 首次启动自动加载并运行 AND 示例；
- 默认界面面向初学者，专业信息按需展开；
- 默认主题跟随系统，同时支持深色和浅色主题；
- 琥珀色表示高电平，冷灰蓝色表示低电平，紫色表示未知 `X`，珊瑚色表示错误，薄荷色表示成功或就绪；
- 颜色不单独承担状态表达，必须配合文字、线型、方向或图标；
- 信号连线的状态变化作为产品的主要视觉记忆点；
- 第一版提供“运行一次”和“连续运行”，单步执行放入高级控制；
- 元件第一版通过点击添加，后续再扩展拖拽放置；
- 使用语义 Token 管理颜色，组件不得直接依赖主题专属色值。

## 结果

- 初学者可以通过示例电路直接进入输入—求值—输出的核心闭环；
- 产品拥有区别于通用后台的电路领域视觉语言；
- 深色和浅色主题可以共享组件结构和状态语义；
- 高级诊断能力不会阻塞基础学习路径；
- 画布、节点、端口、连线、波形和状态反馈可以围绕同一套信号语义演进；
- 需要为主题 Token、组件状态、画布交互和可访问性建立可重复的验收步骤；
- 后续若加入更复杂的时序逻辑、波形和调试功能，需要继续控制默认信息密度。

## 未采用的方案

### 通用 SaaS 卡片风格

这种方案实现成本低，但无法表达电路结构和信号传播，也容易让画布变成普通卡片集合。

### 纯专业 EDA 风格

这种方案能表达工程能力，但默认信息密度过高，不符合初学者优先的产品定位。

### 单一霓虹深色主题

这种方案容易突出实时信号，但不利于长时间使用、打印或浅色环境使用，也会让不同状态之间的语义边界变弱。
