# ADR 0028：Windows 安装交付与故障后的状态边界

Phase 6 首发使用 Windows x64 当前用户安装器，Electron 与 C++ 引擎作为同一版本交付。引擎放在安装资源目录，MinGW 运行库静态链接；生产包只读取随包引擎和本地构建页面。这样用户无需开发工具，更新也不会把不同版本的桌面端和引擎拼在一起。开发环境保留引擎替换和 E2E 页面入口，安装版忽略这些环境变量。

沿用 [ADR 0023](0023-document-keyed-engine-client-pool.md) 的文档隔离：请求超时、无效协议输出或超出响应上限意味着客户端无法确认引擎结构是否已变更。此时终止该进程并进入既有进程死亡恢复路径，由健康检查显式重启、工作区重推文档；不能继续发送业务请求并假设旧状态有效。重建保留编辑器文档，时序状态与波形仍遵循原有恢复限制。

诊断日志仅写本机，采用事件与字段白名单、大小轮转和有界队列；不写工程内容、路径、协议全文或原始 stderr。日志不可写时停用诊断，不阻止保存和仿真。主进程未捕获异常与渲染进程崩溃以可见错误结束应用，避免带着未知状态继续写文件。

发布门槛包含基础验证、真实 Electron 回归、干净 PATH 的打包程序回归以及安装/卸载验收。标签发布工作流创建草稿 Release，正式公开前保留维护者审核；本阶段不引入自动更新。代码签名取决于维护者提供的证书，没有证书时明确交付未签名安装器，不能宣称 SmartScreen 信任或签名验证已完成。
