# ADR 0010：引擎离线时保持编辑器与电路结构一致

## 状态

已确认

## 决策

`EditorSession` 通过一个只返回布尔值的可用性 seam 了解引擎是否可接受结构事务。引擎不可用时，添加、删除、创建连接、重接、清空以及它们的结构撤销/重做都被拒绝并保留可重试的本地快照；视口、节点位置和 Wire Route 仍可在编辑器模型中修改。引擎状态本身继续由 `WorkspaceSnapshot` 管理，不进入 `EditorSnapshot`。

每个成功的 Circuit 结构事务都会在发布完成快照前请求一次稳定求值。稳定求值失败（例如组合逻辑环路）只写入独立的仿真错误，不回滚已经提交且合法的编辑器结构。结构事务失败仍按既有补偿策略处理；补偿失败进入 `recovery-required` 并暂停后续结构命令。

## 后果

- 离线期间用户可以继续整理布局和路线，恢复引擎后可重试待放置或结构意图；
- Vue 只收到编辑器错误/仿真错误和工作区展示状态，不接触引擎身份或协议错误对象；
- 恢复状态需要显式重新加载或由组合层重新初始化会话，避免在未知 Circuit 状态上继续结构编辑。
