# ADR 0002：分离电路结构、编辑器展示和仿真状态

## 状态

已接受

## 背景

电路编辑器需要保存元件位置和视觉状态，仿真引擎需要保存信号值和触发器状态。如果这些信息都放进 Circuit，领域模型会同时承担结构、展示和运行时职责。

## 决策

分成三个概念：

- `Circuit`：静态电路结构；
- 编辑器模型：元件位置、尺寸、选中状态和 Wire 形状；
- `SimulationState`：当前信号值和时序元件状态。

项目文件将来可以同时持久化这三类信息，但持久化格式不代表它们属于同一个领域对象。

## 原因

- 画布移动元件不应改变仿真结果；
- 同一份 Circuit 可以创建多个不同的 Simulation；
- 仿真引擎不需要依赖 UI；
- UI 和仿真可以分别测试；
- 未来增加 CLI 或其他界面时可以复用 Circuit 和 Simulation。

## 后果

- 需要在编辑器模型和 Circuit 之间维护映射；
- 保存项目时需要处理多个部分；
- 初期模型数量略多，但每个模型职责更清晰。
