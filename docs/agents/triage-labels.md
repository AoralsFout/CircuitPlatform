# Triage Labels

工程技能使用五种标准 triage 角色。本文件将角色映射到 GitHub 中的实际标签。

| 标准角色          | GitHub 标签       | 含义                        |
| ----------------- | ----------------- | --------------------------- |
| `needs-triage`    | `needs-triage`    | 等待维护者评估              |
| `needs-info`      | `needs-info`      | 等待报告者补充信息          |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或处理          |
| `wontfix`         | `wontfix`         | 已决定不处理                |

技能提及标准角色时，使用对应的 GitHub 标签。若仓库以后采用其他标签名称，只修改本表右侧映射。
