# CircuitPlatform 前端设计规范

## 文档状态

- 版本：0.1
- 状态：已确认方向，待随组件实现迭代
- 适用范围：`apps/desktop` 的 Vue 桌面应用
- 最后更新：2026-09-13

## 1. 产品定位

CircuitPlatform 是面向初学者的数字电路仿真工作台。界面需要具备专业电路工具的结构和可信度，同时通过清晰层级、直白文案和即时反馈，帮助用户理解“输入如何影响输出”。

设计语言定位为：**引导式数字电路工作台**。

它借鉴实验仪器台和工程图纸的视觉语汇，但不追求复杂 EDA 软件的密度。中央画布是主要工作区，信号连线是主要记忆点，颜色只表达明确的状态含义。

## 2. 体验原则

1. **先看懂，再深入**：默认界面优先展示名称、值、关系和下一步动作；端口 ID、组件 ID 和引擎数据按需展开。
2. **结构优先**：节点、端口、连线和波形服务于电路关系，不使用无意义的卡片或装饰。
3. **状态可见**：仿真、保存、引擎连接、连接校验和错误状态都必须有持续且可理解的反馈。
4. **信号是主角**：高电平、低电平和未知状态在节点、端口、连线和波形中保持一致。
5. **动作说人话**：使用“运行一次”“添加元件”“连接端口”等用户能直接理解的动词。
6. **渐进式专业能力**：初学者默认路径保持简单，高级检查和诊断能力仍然可达。
7. **可恢复操作**：删除、清空、加载和保存失败都必须提供恢复或继续操作的路径。

## 3. 核心工作流

```text
检查仿真引擎
  ↓
加载并运行 AND 示例
  ↓
修改输入
  ↓
观察节点、连线和输出变化
  ↓
按需展开波形和详细属性
  ↓
添加、连接并保存自己的电路
```

首次启动不显示真正的空白画布，而是自动加载一个可运行的 AND 示例。示例完成第一次求值后，画布提示用户切换输入 A 或输入 B。

## 4. 信息层级

### 默认层

面向所有用户，必须直接显示：

- 元件名称；
- 输入和输出端口；
- 当前信号值 `0 / 1 / X`；
- 当前仿真状态；
- 当前可执行的主要操作。

### 详情层

选中对象或展开检查器后显示：

- 元件类型；
- 端口名称和连接关系；
- 组件 ID；
- 仿真状态；
- 波形数据；
- 引擎诊断信息。

详情层不能替代默认层，也不能要求初学者理解内部协议字段才能完成基础任务。

### 5.4 状态语义

| 状态 | 颜色 | 附加表达 |
| --- | --- | --- |
| 高电平 `1` | `--color-signal-high` | 实线、数值 `1`、轻微光晕 |
| 低电平 `0` | `--color-signal-low` | 实线、数值 `0` |
| 未知 `X` | `--color-signal-unknown` | 虚线或点划线、数值 `X` |
| 就绪 / 成功 | `--color-status-success` | 状态点或结果文字 |
| 警告 | `--color-status-warning` | 警告图标和说明 |
| 错误 / 非法 | `--color-status-error` | 图标、边框和具体文案 |
| 键盘焦点 / 当前选择 | `--color-focus` | 外轮廓，不能只改变背景 |

颜色不能单独承担状态表达。信号状态还必须通过文字、线型、方向或图标表达。

## 6. 字体与排版

```css
:root {
  --font-display: "Cambria", "Georgia", serif;
  --font-body: "Bahnschrift", "Segoe UI", "Microsoft YaHei", sans-serif;
  --font-data: "Cascadia Mono", "Consolas", monospace;
}
```

| 层级 | 尺寸 | 用途 |
| --- | --- | --- |
| Display XL | 64–76px | 页面主标题 |
| Display L | 40–52px | 工作区标题 |
| Heading | 20–28px | 面板标题 |
| Body | 13–15px | 正文和操作说明 |
| Label | 10–12px | 工程标签和状态标签 |
| Data | 12–16px | 信号值、端口名和组件 ID |

规则：

- 标题可以使用衬线字体，按钮和状态不得使用衬线字体；
- 端口名、信号值和 ID 使用等宽字体；
- 中文正文使用句首大写的自然句式，不强行全大写；
- 英文工程标签可以使用大写和字距，但只作为辅助信息；
- 正文行高通常为 `1.5–1.7`；
- 重要信息不能只依靠小字号和低对比度表达。

## 7. 尺寸与布局

### 7.1 基础间距

```text
4px   最小图标间距
8px   紧凑控件间距
12px  标签和内容间距
16px  组件内部常规间距
24px  面板区块间距
32px  页面区块间距
40px+ 页面级留白
```

### 7.2 工作区

```text
应用外壳
├── 顶部状态栏
├── 编辑 / 仿真工具栏
├── 主工作区
│   ├── 元件和属性面板
│   └── 电路画布
└── 底部仿真 / 波形区域
```

中央画布是主工作区。左侧面板可以折叠，波形查看器默认收起。窗口缩放时优先保持画布可用空间，不让工具栏和状态栏被压缩到不可读。

## 8. 核心组件规范

### 8.1 Button

```text
Primary      高 40px，水平内边距 16px
Secondary    高 36px，水平内边距 14px
Compact      高 30px，水平内边距 10px
Icon button  32×32px 或 36×36px
```

主按钮只用于当前区域最重要的动作，第一版通常是“运行一次”。按钮状态必须包含默认、悬停、按下、焦点、禁用和执行中。

执行中的文案要明确变化：

```text
运行一次 → 仿真中… → 仿真完成
```

### 8.2 CircuitNode

节点是可操作的电路元件，不是普通卡片。

```text
最小宽度       144px
常规宽度       160–220px
最小高度       72px
内边距         14–16px
圆角           6px
边框           1px
```

推荐结构：

```text
CircuitNode
├── typeLabel
├── displayName
├── inputPorts
├── outputPorts
├── signalValue
└── statusMessage（可选）
```

选中节点时使用焦点色外轮廓，并同步强调相邻端口和连线。节点本身不应整体变成信号色。

### 8.3 Port

```text
视觉圆点直径     8px
可操作命中区域   至少 24px
端口标签         10–11px 等宽字体
```

端口颜色遵循信号 Token。输入和输出必须通过位置、方向和标签区分，不能只依靠颜色。

连接交互时：

- 可连接端口显示薄荷色外圈；
- 不可连接端口显示珊瑚色外圈；
- 取消连接后不留下临时线；
- 释放后立即显示连接结果；
- 非法连接必须说明原因。

### 8.4 SignalWire

连线默认使用水平、垂直和 90 度转角的正交线路，可使用轻微圆角转角，不使用大幅贝塞尔曲线作为编辑器默认样式。

```text
普通连接       2px 冷灰蓝色实线
高电平         3px 琥珀色实线 + 很弱的光晕
低电平         2px 深灰蓝色实线
未知 X         2px 紫色虚线
选中连线       蓝色外轮廓
非法连接       珊瑚色虚线
```

动画只用于信号变化或连续仿真，不允许所有连线持续发光或移动。

### 8.5 Panel 和 Inspector

左侧默认显示元件列表。选中对象后切换为属性检查器。

默认属性：

- 元件名称；
- 元件类型；
- 当前输入和输出；
- 一句话行为说明。

详情属性：

- 组件 ID；
- 端口 ID；
- 连接关系；
- 仿真状态；
- 引擎诊断信息。

### 8.6 WaveformViewer

波形默认收起，发生输出变化后提示用户可以展开。每条信号独占一行，左侧显示名称，时间轴使用等宽数字，当前时间步使用焦点色竖线。

波形必须同时使用颜色和 `0 / 1 / X` 文本表达状态。

## 9. 仿真控制

### 运行一次

这是初学者的主要操作。执行稳定求值、更新节点和连线、更新输出和波形，并在底部状态栏反馈结果。

### 连续运行

文案固定为：

```text
开始连续运行 → 暂停仿真 → 继续仿真
```

运行中显示连续仿真状态、步数或时钟信息。连续运行不能隐藏暂停入口。

### 单步执行

属于高级仿真控制，文案使用“执行下一步”，不放在初学者默认工具栏的主要位置。

## 10. 空状态与错误状态

每个状态都要说明发生了什么以及用户可以做什么。

### 用户清空后的空画布

```text
还没有电路

从左侧选择一个元件，或加载一份示例电路开始。

[添加元件]  [加载示例]
```

### 未连接的电路

```text
元件还没有连接

从一个输出端口拖到输入端口，建立第一条连接。
```

### 系统错误

```text
仿真引擎不可用

电路编辑仍然可以继续，但暂时无法运行仿真。

[重新检查引擎]
```

错误不能只通过短暂 Toast 告知，也不能只使用红色。

## 11. 动效与可访问性

- 只为状态变化、操作结果和当前关系使用动效；
- 不使用持续呼吸或高频闪烁作为常规装饰；
- 支持 `prefers-reduced-motion: reduce`；
- 所有可操作元素支持键盘焦点；
- 焦点状态使用清晰的外轮廓；
- 端口的实际命中区域至少为 `24×24px`；
- 错误、成功和信号状态不能只依靠颜色；
- 重要状态使用 `aria-live` 或等效的可访问反馈；
- 画布操作应提供键盘等价路径，至少支持选择、删除、取消和撤销。

## 12. 键盘操作

```text
Ctrl/Cmd + Z              撤销
Ctrl/Cmd + Shift + Z      重做
Delete / Backspace        删除选中对象
Esc                       取消连接或退出当前操作
Enter / Space             执行当前聚焦的按钮或开关
```

删除元件会同时删除相关连线，但必须可以通过撤销恢复。清空整个画布需要确认。

## 13. 文案规范

使用用户能直接理解的动作和结果：

```text
运行一次
添加元件
连接端口
查看输出
保存电路
```

避免把内部实现词汇直接暴露给初学者：

```text
Execute
Settle
Mutate
Recompute
```

错误文案采用三段信息：

```text
发生了什么
为什么会发生
用户下一步可以做什么
```

## 14. 工程落地规则

1. 颜色、字体、间距和尺寸通过 Token 管理。
2. 组件样式不得随意新增主题颜色。
3. 页面布局样式和组件状态样式分离。
4. `CircuitNode` 只负责展示和抛出交互事件，不直接负责仿真流程。
5. 连接创建、仿真触发和状态管理由画布控制器或领域层负责。
6. 公共组件需要覆盖默认、悬停、按下、焦点、禁用、错误和执行中状态。
7. 视觉变更至少通过可重复的手工验收步骤验证。
8. 重要设计变化同步更新本文档和 `docs/decisions/` 中的决策记录。

## 15. 实现验收清单

- [ ] 深色和浅色主题均可切换。
- [ ] 默认主题跟随系统，用户选择可以持久化。
- [ ] 首次启动会加载并运行 AND 示例。
- [ ] 输入、输出和连线的 `0 / 1 / X` 状态在两个主题中均可辨识。
- [ ] 运行一次、连续运行和暂停状态的文案清晰一致。
- [ ] 非法连接有明确原因和可恢复路径。
- [ ] 删除元件可以通过撤销恢复。
- [ ] 波形查看器默认收起，展开后有清晰时间轴和信号标签。
- [ ] 键盘焦点可见，减少动效设置生效。
- [ ] 引擎不可用时仍可继续编辑电路。

## 16. 待后续决策

- 元件符号是否采用统一的 IEC 风格，还是使用更适合教学的简化符号；
- 电路画布是否需要小地图；
- 保存文件格式和最近项目入口；
- 波形查看器的时间步、时钟和光标交互；
- 是否提供初学者 / 专业两个显示密度档位。
