# 学习路线

每个阶段都必须包含学习目标、一个可运行的交付物、自动化测试和复盘。

## Phase 0：脚手架

学习 Git、Monorepo、Electron、CMake、进程通信和基础测试。交付空桌面应用、空 C++ 引擎和健康检查闭环。

## Phase 1：领域模型

定义 Circuit、Component、Port、Wire、Net 和 Signal，记录不变量并编写领域测试。

## Phase 2：组合逻辑

实现输入、输出和基础逻辑门，完成稳定求值、错误建模和组合环路检测。

## Phase 2.5：跨进程协议

通过 JSON Lines 和 Electron IPC 暴露一个最小可用的引擎会话，学习协议设计、请求响应匹配、进程生命周期、错误收敛和集成验证。交付“创建结构 → 设置输入 → 稳定求值 → 读取信号”的可复现命令链。

## Phase 3：图形编辑器

使用 SVG 实现元件拖动、选择、连线和属性编辑，并保持界面模型与领域模型分离。

## Phase 4：时序逻辑

实现 Clock、D Flip-Flop、tick、上升沿、reset 和状态快照。

## Phase 5：波形和持久化

实现简单波形、项目文件、版本字段和加载校验。

## Phase 6：工程化和发布

完善 CI、日志、错误处理、打包、发布文档和回归测试。

## 每个任务的教学循环

```text
概念讲解 → 小任务 → 自主实现 → 测试验证 → 代码评审 → 重构 → 复盘
```
