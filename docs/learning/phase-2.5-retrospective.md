# Phase 2.5 复盘：跨进程协议

## 交付结果

本阶段完成了从 Electron 到 C++ 引擎的最小可用会话：创建元件、创建连接、设置输入、稳定组合逻辑并读取信号。C++ 进程持有一份 `Circuit`，Electron 主进程通过 `EngineClient` 复用长连接，渲染进程只接触 preload 业务接口。

## 本阶段工程学习

- 用 JSON Lines 把请求边界做成可观察、可管道复现的协议；
- 用 `requestId` 将异步响应和请求解耦；
- 将协议适配、Electron IPC 和仿真核心拆成三个可替换层；
- 在结构变化时重建运行时快照，用简单明确的规则控制状态生命周期；
- 用 C++ 单测、Node 端到端脚本和 `pnpm verify` 组成分层验证。

## 仍待改进

- C++ 当前使用受控的最小 JSON 解析器，后续若协议复杂化应评估成熟 JSON 库；
- IPC 参数校验还较薄，正式编辑器接入时需要统一输入校验和错误展示；
- 当前协议尚未暴露删除元件/连接，需在保持悬空连接规则的前提下补齐；
- `clock` 和 `d_flip_flop` 目前只有结构定义，没有时序求值。

## 下一阶段建议

先接入一个极小的编辑器用例：在 Vue 中创建两个 Input、一个 AND 和一个 Output，调用协议完成连线和求值，并显示输出信号。这样可以学习 UI 状态、用户操作和领域命令之间的映射，同时继续保持仿真规则只存在于 C++。
