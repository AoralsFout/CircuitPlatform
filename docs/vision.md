# 项目愿景

## 项目是什么

CircuitPlatform 是一个简易的数字电路仿真桌面应用。用户可以创建逻辑元件、连接电路、设置输入并观察输出和状态变化。

## 工程目标

项目以清晰边界、可验证行为和可演进架构为目标：

- 需求分析和范围控制；
- 领域建模；
- 模块接口设计；
- 前后端协作；
- C++ 工程实践；
- 自动化测试；
- 构建、持续集成和发布；
- 技术债务和重构。

## 产品范围

第一版支持组合逻辑和基础时序逻辑，包括基础逻辑门、Clock、D Flip-Flop、`0 / 1 / X` 信号、手动和连续仿真、保存加载以及简单波形查看。

## 非目标

当前不实现模拟电路、SPICE、PCB 布局、FPGA 综合、完整 Verilog 编译器、多用户协作和云端项目管理。
